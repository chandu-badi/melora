# Melora
A private Spotify-style music app starter. Plain HTML, CSS and JavaScript with a hosted audio catalogue of six original 32-second instrumental demos generated by `generate_audio.py`.

## Working features
Responsive discovery, mood filters, live search, playback/pause, next/previous, seek, volume, shuffle, repeat, queue, favourites, playlist creation/rename/deletion and track management. Playlists and favourites are local to the browser. On narrow mobile screens the player presents compact playback controls.

## Scope and security
The Sites deployment is owner-private with platform authentication. No custom passwords or payment collection. No external scripts, fonts, trackers or dependencies. CSP restricts script and media to the same origin and disables connections, forms and objects. User-entered playlist names render through textContent. Stored library data is validated on load. No uploads, user-supplied URLs or remote fetches. Browser storage is not a sensitive-data store or cross-device account system. This is a starter, not a security-audited commercial streaming service.

## Before a public commercial release
Choose a licensed audio provider and verify its streaming permissions. Implement server-side per-user storage and authorization, account deletion, rate limits, supported authentication, catalogue access control, logging/monitoring and abuse controls. Configure response security headers and conduct deployment-specific security and accessibility testing. Add provider credentials only as server runtime secrets. Use an audited payment provider if subscriptions are needed. Do not embed API secrets or copyrighted music without appropriate permission. Shared rooms and community chat are out of scope.

## Development
Generate the audio before serving the app (WAV files are build outputs and are not checked into GitHub):

```sh
mkdir -p dist/assets
python generate_audio.py
node --check dist/app.js
python -m http.server 8000 --directory dist
```

Open http://localhost:8000. Python 3 and Node.js are needed for the generation and check; the app itself has no runtime dependencies. GitHub Actions runs the checks, generates the audio and uploads a complete `melora-static-app` artifact. Download and unzip the artifact to obtain a ready-to-serve static app.
